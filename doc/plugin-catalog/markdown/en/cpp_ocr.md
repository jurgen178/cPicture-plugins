### OCR – Text Recognition

This function plugin recognizes text in selected images using the built-in Windows OCR engine. No API key or internet connection required.

The recognized text is shown in a dialog and can be copied to the clipboard with a single click. For multiple selected images, the results are combined with the file name as a section header.

**Requirements:** Windows 10 or higher. The OCR engine uses the language packs installed on the system.
