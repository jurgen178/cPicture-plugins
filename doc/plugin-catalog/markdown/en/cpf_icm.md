### ICM/ICC Color Profile

This format plugin displays ICC and ICM color profiles as an image preview.

The preview contains profile metadata and a CIE 1931 xy diagram. RGB matrix profiles show primaries and white point; complex LUT, CMYK, and printer profiles are shown as a metadata view.

This plugin is built on Little CMS.

Website: [Little CMS](https://www.littlecms.com/)
