### AVIF-Format

Dieses Formatzusatzmodul erweitert cPicture um die Unterstützung des AVIF-Bildformats. AVIF-Bilder können geöffnet und gespeichert werden.

Dieses Plugin basiert auf libavif.

GitHub: [libavif](https://github.com/AOMediaCodec/libavif)

Hinweis: AVIF nimmt sich beim Laden spürbar mehr Zeit und beim Speichern gern eine kleine Ewigkeit.
